# Dhaval Gondaliya — Portfolio

Personal portfolio of Dhaval Gondaliya, Backend Developer (Node.js, NestJS, PostgreSQL, MongoDB, AWS).

Built with Next.js (App Router) and TypeScript, no UI framework.

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Editing content

All text — profile, projects, skills, experience — lives in [`data/profile.ts`](data/profile.ts).
The résumé download is [`public/Dhaval_Gondaliya_Resume.pdf`](public/Dhaval_Gondaliya_Resume.pdf).

## Deploy

Import the repo on [Vercel](https://vercel.com/new) — no configuration needed.
